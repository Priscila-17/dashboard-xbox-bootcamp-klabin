# Dashboard em Excel – Bootcamp DIO

## Objetivo
Este projeto apresenta um dashboard em Excel para análise de vendas de assinaturas Xbox.

## Arquivos do repositório
- dashboard.xlsx: arquivo Excel com o dashboard final.

## Dados utilizados
Foi utilizada uma base de dados fictícia com informações relacionadas a assinaturas da Xbox, incluindo tipos de plano, valores, período de adesão, período de renovação e status de assinatura.

## Como reproduzir
1. Baixe este repositório.
2. Abra o arquivo `dashboard.xlsx` no Excel.
3. Se aparecer um aviso de segurança, clique em **Habilitar Edição**.
4. Aparecerá um dashboard com opções na lateral esquerda. São os filtros do dashboard, use-os para explorar os dados.
